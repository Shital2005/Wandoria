## ⚙️ Getting Started

Follow these steps to run Wandoria on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/Shital2005/Wandoria.git
```

**2. Navigate to the project directory**

```bash
cd Wandoria
```

**3. Run the website**

Open `index.html` in your preferred web browser, or use the Live Server extension in Visual Studio Code.

No additional dependencies or package installation are required.

## 🎯 Project Objective

The objective of Wandoria is to practice frontend development fundamentals and create a visually engaging website for a travel company, with a focus on layout design, typography, navigation, and user interface styling.
